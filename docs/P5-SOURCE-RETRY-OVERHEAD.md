## Implementation interface decisions — 2026-10-03

The registered developer reads one Recovery result. Each admitted retry chain keeps the original chain/group/session/turn IDs, failed and terminal-success event IDs, decisive observation IDs and result boundaries. Duration coverage counts selected, measured and unavailable failed attempts with the unchanged native timing exclusion names. Duration cohorts are keyed by session, stored duration scope and timing evidence, and retain exact event membership and a nullable checked sum. A chain/source duration scalar requires complete coverage and one compatible cohort; evaluated empty input is zero. Fractional duration arithmetic is finite and bounded by `Number.MAX_SAFE_INTEGER`, without an integer-only rule.

Interval partitions are keyed by session, interval scope and interval evidence. Each partition retains chain and failed-event membership and unions all positioned failures across those chains. A source elapsed scalar requires one partition; multiple partitions remain individually visible with a null scalar and an explicit reason. Chain overhead remains independent of duration eligibility. Both scalar kinds distinguish incompatible evidence, incomplete duration coverage, numeric overflow and unavailable Recovery evidence.

The DTO copies Recovery generation/availability/capabilities/readiness fields and a compact inherited context containing its summary, classification, inventory, provenance, mapped session status/reasons/missing or blocked references, unavailable groups and limitations. Admitted Recovery groups and their complete rows are not duplicated; retry chains retain their admitted proof. This preserves blocked known failures and pending/group/session reasons without running Recovery or native admission again. The human formatter shows bounded cohort/partition/chain/session/group detail with exact omissions; JSON retains complete bounded membership. Existing stats wiring already selects only this analyzer and validates boolean/conflicting flags before storage, so edits there are needed only if focused verification exposes a defect.

`summaryScope=admitted_recovery_chains` explicitly names the selected subset. Partial Recovery does not suppress valid admitted measurements. Missing/incompatible selected durations make the duration scalar null while its measured cohorts remain visible; one compatible admitted interval partition can retain its observed union. Inherited blocked group/failure counts and reasons qualify those subset values. Source cohorts and interval partitions refer to chain IDs; each chain retains failed-event and decisive-observation membership once, and its duration measurements identify their failed events. Only Recovery sessions with blocking reasons require inherited detail. This avoids duplicating the complete admitted Recovery rows and proofs within the 8 MiB CLI JSON envelope.
