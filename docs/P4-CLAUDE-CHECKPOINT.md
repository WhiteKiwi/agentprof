## Goal and boundary

Preserve exact bounded continuation of one ordinary Claude adapter across a serialized checkpoint. Existing public snapshots omit private call/result digests, positions, source/stream state, deferred results, replay sets, usage ordering, diagnostic keys and counters. Reconstructing only public rows is insufficient.

This is an adapter-only API. It reads no files and changes neither SQLite, scan/cache behavior nor CLI output. A supplied completedOffset is caller metadata, not evidence of an LF boundary or the bytes preceding it. A future scanner MUST independently validate the source generation and exact source-prefix bytes, actual completed LF boundary, interpretation limits and atomic generation relationship before seeking. The keyed checkpoint tag authenticates serialized adapter state under the supplied identity context, not the original log or caller's physical claims. It is neither encryption nor a defense against a caller that possesses the same identity signing context.

Ordinary means no trustedFixtureContext was supplied to any ingest attempt contributing to this adapter lifetime. Synthetic fixture JSON may be used as ordinary inert input, but no trusted timing, finality, complete-output or copied-origin proof is accepted by the recovery API. Multiple streams and ambiguous ordinary origin within a single source remain representable. State-limit and dropped-diagnostic counters are preserved where bounded serialization can represent the full retained state. They do not become full coverage.

Both ingestion readiness flags stay false. Durable storage, offset scanner resume, copied/archive reconciliation, cross-source merging, global aggregation, report work, actual-user-log sampling and performance claims are outside this slice.

## Adapter API

- ClaudeAdapter.exportCheckpoint(binding, options?) returns either a frozen captured result containing an opaque string, or a frozen unavailable result with one fixed safe reason and no partial string.
- ClaudeAdapter.restoreCheckpoint(context, encoded, expectedBinding, limits?) is a static factory. It returns a frozen restored result containing a NEW ClaudeAdapter, or a fixed rejected result with no adapter. It never mutates an existing instance.
- Binding fields are sourceId (existing keyed Claude source identity), completedOffset, nextOrdinal. Restore requires exact caller-expected values. A sourceId is computed by existing fingerprint("source", ["claude", fileIdentity]); no raw fileIdentity is serialized.
- Effective limits use exactly the existing DEFAULT_CLAUDE_LIMITS plus validated caller overrides. All effective names and values are authenticated and must match restore's selected limits. This API adds no provider semantic limits and changes no existing snapshots or upsert batches.
- Export options may lower maxBytes from the fixed 4 MiB UTF-8 envelope ceiling. Restore uses the same fixed ceiling. A lower export budget only changes checkpoint availability, not adapter acceptance or state.
- Safe reasons distinguish unsupported/trusted or multisource state, unsafe source positions, incompatible binding, checkpoint budget, and invalid checkpoint. No raw input, exception text or partially restored state escapes.

## Physical position accounting

Production ingestion currently starts ordinal at zero; the existing Claude test helper starts at one. The adapter itself accepts nonnegative safe integers. Track firstOrdinal from the first valid source descriptor rather than assuming a one-based convention. Require subsequent ordinals to be consecutive and source byte starts strictly increasing for checkpoint eligibility. Keep firstOrdinal, lastOrdinal, lastByteOffset, recordCount and keyed sourceId only. Track a valid source descriptor before existing record-shape early returns, including primitive/null/array raw records, without changing diagnostic or ingest behavior. Do not retain raw record bodies or raw source identity.

For nonempty state, lastOrdinal + 1 must be a safe integer equal to binding.nextOrdinal; lastByteOffset must be strictly less than completedOffset; recordCount must equal lastOrdinal - firstOrdinal + 1. For empty state completedOffset=0 and nextOrdinal is any caller-selected nonnegative safe integer, including0 or1; this authenticated value is enforced on the first restored descriptor. Production uses0. Empty state still binds the expected keyed source ID, and the first continuation must use that source and next ordinal. Valid leading blank lines/BOM do not require first record offset zero. The tracked starts cannot prove line lengths, no skipped physical records or prefix coverage; that remains external validation.

An invalid descriptor, unexpected source, trusted fixture involvement, nonconsecutive ordinal or nonincreasing offset permanently makes this adapter lifetime unavailable for checkpoint export without changing existing ingest semantics. A restored adapter starts its tracker at the authenticated continuation position. Its first accepted continuation descriptor must have byteOffset >= authenticated completedOffset and ordinal == authenticated nextOrdinal. A position inside the old completed prefix is not continuation merely because it is after the prior record start. Source mismatch or invalid continuation descriptor makes later export unavailable while preserving existing ingest semantics. Ordinary semantic replay at later physical positions remains supported and is not physical reordering.

## Exact envelope and keyed framing

The opaque outer string is JSON.stringify({schema:"agentprof.claude-checkpoint/v1",payload,tag}), with precisely those three keys in that order. payload is an opaque JSON string produced by the versioned checkpoint writer; tag is:

fingerprint("source", ["agentprof.claude-checkpoint/v1", sha256(UTF8(payload)).hex])

The existing identity implementation is HMAC-SHA256 over JSON.stringify([normalizationVersion,keyVersion,domain,...parts]) using its private KeyObject, returned as h1:keyId:domain:hex. The explicit checkpoint namespace prevents collision with the ordinary source identity framing. Only the 64-character SHA-256 digest, not the whole payload, enters the existing bounded identity call. Compare fixed-length validated tag bytes with timingSafeEqual. The sourceId, keyId, keyVersion, normalizationVersion, parserVersion, effective limits, binding and every retained-state field are INSIDE payload.

parserVersion must be read from the actual Claude capabilities identity used by this implementation (currently1), not an unrelated checkpoint literal. Checkpoint schema version is independent. Restore compares all identity/version/binding fields to the new adapter/context. Same keyId with a different secret fails the tag. The helper does not import DB validators or couple parser recovery to SQLite.

## Raw-free state schema

The payload has exact fixed fields for versions/binding/limits/position and state. Maps are ordered arrays of [key,value]; sets are ordered arrays of values. Preserve insertion order because snapshots, upsert batches, diagnostics and budget behavior depend on it.

State contains sources, streams, execution states, turns, usage, usageOrders, messages with digests, uuidReplays, deferredResults, resultReplays, observations, metadata, diagnostics WITH their original private dedup keys, shapes, messageEdges, partial, limited, unsupported, ambiguous and diagnosticsDropped. usageProofReplays is present but must be empty for ordinary state. Existing values retain nullable fields, partial/invalid count representations, unknown timing/finality, conflict and ordering semantics exactly.

Execution states contain safe normalized events plus callDigest, inputDigest, first callProjectId, physical position, callMessageId, callKind, backgroundRequested, safe result and conflicted. Safe results contain only current keyed digest/identities, enums, timestamps, scalar flags, source position and null ordinary-only content/error/direct-timing fields. No raw command, tool input, transcript body, result text, source path, raw UUID/session/tool/message ID, credential or secret is serialized. Ordinary normalized command patterns retain only the existing closed safe vocabulary.

## Validation and atomicity

1. Reject nonstring encoded input. Check UTF-16 length as a cheap bound and actual UTF-8 bytes BEFORE JSON.parse. Maximum outer bytes4MiB. A lexical JSON nesting preflight limits depth16 while respecting quoted strings and escapes.
2. Parse only this bounded outer string. Exact schema keys/types and canonical JSON.stringify equality reject duplicate keys and alternate serialized forms before trusting payload. A duplicated key cannot survive the equality check. The outer payload string and tag lengths are independently bounded.
3. Verify the exact tag before parsing the inner payload. Still enforce payload depth16, canonical serialization equality and exact schema after bounded parse; keyed integrity never substitutes for structural validation. Canonical form preserves writer property order, rejects duplicate keys, nonfinite/overflow encodings and unrecognized text.
4. Validate all retained objects with exact field allowlists; enforce key/domain/version/provider, nullable types, finite safe numbers, safe enum/display vocabularies, timestamp syntax and source bounds. Bound row bytes at64KiB, collections at their effective existing limits, total structural nodes at 4,194,304 (count each object, array, key and primitive once during an iterative walk), and diagnostics at their exact configured cap. Any extra field or non-allowlisted value makes state invalid, even with a recomputed test tag. Privacy sentinel tests verify that raw inputs are not retained; there is no magical substring rejection rule for otherwise-valid keyed hashes.
5. Reject duplicate map/set entries and mismatched key-versus-value identities. Recompute messageEdges from links and validate counters/flags. Check all required private references (execution stream, usage/order pairing, known source positions, private map keys) and preserve deliberately dangling provider message/observation links where existing adapter semantics allow them. Missing future call for a deferred result is VALID, not an invented relationship. State-limit cases must not be rejected merely because the existing bounded adapter omitted an optional graph node; schema must distinguish mandatory internal references from nonasserted provider references.
6. Stage entirely in temporary validated owned objects. Only after every check succeeds instantiate/populate a fresh adapter, reconstruct exact map/set order and counters, and expose it. Freeze nested safe values just as original creation does; mutable private execution/source structures remain private owned copies. Rejected restore exposes no partial instance and cannot alter the source adapter.
7. Export incrementally checks row/count/aggregate budgets before concatenation; it does not serialize an unbounded whole state merely to discover it exceeds the cap. It never invokes user-owned getters/toJSON. Export failure leaves canonical state, counters and subsequent ingest behavior unchanged. Valid in-memory sessions that exceed checkpoint budget continue normally and require byte-zero reparse externally.


## Frozen structural and field rules

The outer/inner total-node ceiling is4,194,304 separately, counted iteratively including each object, array, own key and primitive. Depth is16, measured as nested object/array containers with the root at1. Individual map entries, set strings and shape values are serialized as rows before appending; each row is at most65,536 UTF-8 bytes. The complete escaped outer envelope must fit4,194,304 UTF-8 bytes, including envelope overhead and escaped payload quotes. Count escaped byte growth incrementally, not after a potentially unbounded concatenation. Overflow returns checkpoint_budget without changing live state; safe valid larger adapter sessions remain usable and are simply not checkpointable by v1.

All scalar numbers are finite nonnegative safe integers unless explicitly marked nullable duration (finite nonnegative number <= Number.MAX_SAFE_INTEGER) or timestamp. Private ordinals/offsets/counts and token components are integers. Booleans are actual booleans. Checked arithmetic rejects overflow before count/ordinal updates. Timestamps accept exactly current normalized UTC ISO output or null; do not infer times or require independent endpoints where adapter semantics permit null. Existing duration-only Claude turns keep source_reported duration with unknown scope. Unknown, invalid and conflicted values are retained rather than recomputed into eligible values.

Every object has an exact field set, with no accessors, symbols, prototype keys or additional raw fields. Restore inputs are parsed JSON, not executable object graphs. Export builds owned plain data from private state. Every keyed identity matches h1:<expected keyId>:<required domain>:64 lowercase hex; null is allowed only where current types permit it. All sourceRef.fileId and position.fileId equal binding.sourceId. Every retained byteOffset is < completedOffset and <= tracker.lastByteOffset. Retained position.ordinal is between tracker.firstOrdinal and tracker.lastOrdinal and its position.sourceRef.byteOffset is its actual retained start. Safe aliases are null or /^source-[0-9]{1,12}$/.
