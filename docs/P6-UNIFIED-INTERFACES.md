The same boolean flag composes with the existing explicit `--provider codex|claude --input FILE.jsonl` and optional `--open` paths. No new CLI command, implicit source discovery or date inference. Omitted/false flag preserves the old report implementation and its outputs. Reject nonboolean internal values and duplicate CLI flags before private I/O; require ordinary .html/.htm output for the new layout. New unified tests and these scoped plans are reserved; #136's stats/main hunks and #50 remain untouched.

The composite model runs each requested top-level analyzer on the same StoredSource object; sub-analyzers may reuse their internal admission functions. Claim only one pinned source read, not one global native-admission invocation. Summary, native command breakdown/Slow Tool, failures, retry duration versus interval union, observed recovery, read/search recurrence, and pattern/edit-validation sections keep their own support and population gates. A bounded interval table contains only positioned events admitted by pattern time partitions, not an inferred critical path. Shared aliases have the same meaning across sections.
